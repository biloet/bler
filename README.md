# BLER

Landing page "Your profile. Now a market." — static site (HTML/CSS/JS, tanpa build step).

## Jalankan lokal

Buka `index.html` langsung di browser, atau:

```bash
npx serve .
```

## Struktur

- `index.html` — markup halaman
- `styles.css` — styling (dark theme, mobile-first)
- `script.js` — chart live, daftar profil, modal wallet & launch
- `assets/logo.svg` — logo BLER

Catatan: tombol wallet dan launch masih demo UI (belum terhubung ke blockchain).
